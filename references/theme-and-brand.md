# 主题变量与品牌

新绘页面的最低品牌变量在 Skill `assets/brand/brand-baseline.json`，精确配色由 `assets/brand/brand-palette-lock.json` 锁定，蓝／红／深蓝三套基础色系、黑白灰中性色与字体角色可离线读取。`audit_brand_palette_source.py --library <知识库目录> --report <报告>` 验证锁定色确实来自对应模板的主题、可编辑对象或科技风来源页渲染图，并核对知识库中性色。知识库 `themes/` 保存原稿主题槽、语义色、中性色、对象绑定和主题专属图片，是模板复用的来源。Skill 本地快照不证明旧模板的全部对象已可一键换色。不得把所有相同 RGB 全局替换：同色可能承担标题、背景、数据强调或 Logo 的不同职责。渐变各色标、透明度、角度和明暗变换需逐对象保留。

新绘页面按所选主题的语义颜色生成；如蓝色系使用 `themes.blue` 的画布、主色、辅色、文字色和边框色。黑、白、浅灰、中灰、深灰及深底次要文字只用 `themes.<选定主题>.neutral`，不得由模型自由生成近似灰、橙、黄、绿或透明白作新装饰。新绘 PPTX 使用 `audit_new_drawn_palette.py` 检查实际页面 RGB 是否全部来自配色锁；离线出稿器内置此门禁。知识库原始 `color_slots` 可能包含模板历史色或科技页的橙绿槽位，不代表它们可以在新绘页面使用；新绘只认所选主题的锁定角色。来源组件中的显式色、渐变、图表或图片保留原视觉并注明来源；新增非品牌色需先增补变量并审核，不能临时写 RGB。验收要看成稿实际颜色及图形来源；只检查主题 JSON 或 Logo 不能证明整稿已按主题换色。

蓝色系浅底与浅灰角色固定为 `F6F9FF`，中灰角色使用蓝色补充模板中已有的 `8BA1C4`。来源封面若含 `E7E6E6`，只作为该封面的来源色保留，不能借作蓝色内容页的画布或信息框。组件页的 `lt2` 应对应知识库蓝色来源主题的 `F6F9FF`。

原稿页常用 `accent1`—`accent6`、`bg1`、`tx1` 等主题引用。跨演示文稿插页或由 WPS 等软件重新保存后，页面可能改挂另一套母版，原本的蓝色图形便可能变成橙、黄、绿。`fill_layout.py` 保存单页后运行 `materialize_component_colors.py`，先将单页的全部 12 个主题色槽与知识库来源页逐项比较；任一槽不同就拒绝固化。通过后根据**该来源页自己的主题和颜色映射**，把页面、所用版式、母版与原生图表的主题色引用写成明确 RGB，同时保留渐变的色标变换。来源原稿不修改；PPTX 格式必需的主题部件仍存在，但可见组件不再靠它取色。`assemble_deck.ps1` 同时运行来源主题审计和 `audit_component_color_independence.py`；最终文件经其他软件保存后也须重跑后者。图表样式的 `phClr` 属独立占位符，出现时单页目视复核。

Logo 原件与 PNG 兼容版已经放在 Skill `assets/brand`，默认加到所有页，不依赖知识库。蓝色风格浅底使用原色 Logo、深底使用白色；科技风深底使用白色。**红色风格统一使用单色 Logo：浅底黑色、深底白色，来源页已有灰色单色 Logo 可保留；禁止蓝红彩色 Logo。** 这条规则同时适用于知识库模板、技能排版和自由编排；红色来源页如带彩色图片 Logo，填充时在原锚点替换为黑／白 Logo，用户显式指定红色彩色 Logo 应报错。复用原稿时优先采用源页有效锚点，次选同家族已验收锚点，最后做四角避让；离线新绘页面使用顶部安全区。任何 Logo 与标题、页码、图形相交均不交付。

SVG 保留原件，PPTX 默认用兼容 PNG 实体；如嵌入 SVG，必须有 PNG fallback，并在 PowerPoint 实测。非 Logo 图标换色只对有语义角色绑定的路径执行；品牌图标或含多色语义的图标单独锁定或逐路径映射。扩展色必须先补对象级绑定并与源稿对照，不可仅改 `theme.xml` 就宣称完成。

# 深蓝科技风补充

科技风专属 `color-inventory-tech.json` 已按 85 个来源页逐对象记录颜色引用、渐变、图片、SVG 和原生图表。清单状态为 `inventory_only_no_recolor_claim`；对象角色仍为 `unmapped_pending_review`，因此不能据此提供跨色系换色。下一步逐对象确认语义角色，并分别验证原生形状、渐变、SVG、图表和封面栅格背景。

`deep-blue-tech` 使用独立的 `themes/new-template-deep-blue-tech.json` 和 `typography/deep-blue-tech.json`。颜色槽与字体角色是首轮提炼，PPTX 中的显式色、渐变、图表和 SVG 仍须逐对象映射和渲染审核。与蓝红简约版相同，可编辑中文展示、标题和正文按任务 `font_profile` 分配中西文字体；字号、字重和行距仍按信息层级设置并复查换行。Logo 原色锁定，不受主题换色影响。调用时显式传入 `style_family=deep-blue-tech`，避免与旧三源混排。
