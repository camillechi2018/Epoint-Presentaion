# 目录项长文案容量

目录页仍选用知识库原稿组件。以下上限是**单个目录项**的中文字符上限，来自各版式 2–8 项或 2–6 项的 PowerPoint 压力样稿；数字、拉丁字母和其他文字还须经过 `max_width_units` 与实际文字边界检查。页标题“目录”的容量单独按绑定字段检查。

| 目录版式 | 风格 | 项标题 | 项说明 |
| --- | --- | ---: | ---: |
| `content-blue-001` | 蓝／红简约 | 4 字 | 16 字，可自动换成两行 |
| `supp-directory-01` | 蓝／红简约 | 8 字 | 无 |
| `supp-directory-02` | 蓝／红简约 | 8 字 | 无 |
| `supp-directory-03` | 蓝／红简约 | 8 字 | 无 |
| `supp-directory-04` | 蓝／红简约 | 8 字 | 无 |
| `supp-directory-04-red-variant` | 红色专属 | 8 字 | 无 |
| `directory-tech-006` | 科技风 | 8 字 | 12 字 |
| `directory-tech-007` | 科技风 | 4 字 | 8 字 |
| `directory-tech-008` | 科技风 | 8 字 | 12 字 |
| `directory-tech-009` | 科技风 | 4 字 | 11 字 |
| `directory-tech-010` | 科技风 | 6 字 | 12 字 |

选版时先按主题、项数和信息关系筛选，再用实际 `items` 检查每一项的标题与说明。超过当前版式容量时换用空间更大的目录；仍放不下时分成两页目录或与用户材料一起压缩措辞，不能静默删字、缩得不可读或放任文字出框。`plan_deck.py` 负责预筛；`fill_layout.py` 在写文件前再次校验。最终稿仍检查实际 PowerPoint 渲染。

这项验收只开放**可编辑 PPTX 静态目录**中的上述受限长文案。HTML、目录动效以及其他页面的长文案各自按原有状态处理。
